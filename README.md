# 迷霧

以台北捷運為舞台的開放世界 RPG。玩家扮演 17 歲高中生**軒宇**或**愛紜**，從任何一個捷運站出發，在路網上自由搭乘探索。

## 怎麼玩

1. 選擇主角（軒宇／愛紜）
2. 選擇出發站：第一站就是起點，之後只能從所在車站繼續搭車
3. 在月台選方向：每個方向**固定 3 分鐘一班**，依台灣真實時間倒數進站
4. 列車進站（各路線有自己的進站音樂），車門開 20 秒：**自己走到車門前按 E 上車**，沒趕上就等下一班
5. 在車廂裡也能走動；到站開門時走到車門按 E 下車，不動就繼續搭到下一站。轉乘站可以換到其他路線的月台

### 操作

- 方向鍵／WASD：走動（左右、前後）
- E／空白鍵／Enter：互動（上車、下車）
- 手機或滑鼠：點地板，角色就走過去；互動按鈕會出現在右下角
6. 搭到任一路線的**終點站**就會得到該路線的物品，共 6 件
7. 集齊 6 件放到指定地點可開啟新地圖（尚未開放）

## 時間

遊戲使用台灣真實時間（Asia/Taipei）。

| 時段 | 狀態 |
|---|---|
| 06:00 – 00:30 | 捷運營運中 |
| 00:30 – 05:30 | 迷霧時刻（特殊玩法，即將開放） |
| 05:30 – 06:00 | 車站尚未開放，等首班車 |

窗外天色也會依時間變成白天、黃昏、夜晚或清晨。

測試時可以在網址後加 `?time=23:55` 模擬台灣時間，例如 `index.html?time=00:28`。

## 路網

台北捷運 6 條路線，共 118 站，含支線與轉乘站：

- 文湖線 BR01–BR24
- 淡水信義線 R01–R28，含新北投支線 R22A
- 松山新店線 G01–G19，含小碧潭支線 G03A
- 中和新蘆線 O01–O21、O50–O54（在大橋頭分往迴龍、蘆洲）
- 板南線 BL01–BL23
- 環狀線 Y07–Y20

## 進站音樂

在 `assets/sounds/` 放入 `arrive-BR.mp3`、`arrive-R.mp3`…等檔案，遊戲會優先播放；沒有檔案時會播各路線的合成旋律。詳見 `assets/sounds/README.md`。

## 執行

純 HTML/CSS/JavaScript，不需要安裝套件。用任何靜態伺服器打開即可：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

也可以直接用 GitHub Pages 發佈。

## 檔案結構

```
index.html
css/style.css
js/data.js        路網資料（車站、路線、站碼、轉乘、地下/高架）
js/characters.js  主角資料與立繪
js/time.js        台灣時間、營運時段、3 分鐘班距
js/audio.js       進站音樂、關門警示音、行駛聲、中英文廣播
js/scenes.js      月台與車廂場景繪製
js/player.js      角色操控（鍵盤、點擊移動、互動）
js/map.js         可縮放的路網圖
js/game.js        遊戲流程
assets/characters 主角立繪（照片去背）
assets/sounds     進站音檔（選用）
```
